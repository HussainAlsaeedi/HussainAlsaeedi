# Data Analytics Portfolio

This portfolio contains independent data analytics projects built from public or synthetic data.
## Portfolio Strategy

The goal is to demonstrate the complete analytics lifecycle:

**Raw Data → Data Cleaning → SQL Analysis → Python Analysis → Data Model → Visualization → Business Insight**

---

## 01 · E-Commerce Revenue & Customer Analytics

**Status:** In development  
**Tools:** SQL, Python, pandas, Power BI, DAX, dimensional modeling

### Business Case
An online retailer wants to understand what drives revenue, which customer groups are most valuable, which products perform best, how repeat purchasing affects growth, and where returns are reducing performance.

### Analysis Areas
- Revenue and order trends
- Average order value
- Customer segmentation
- Repeat purchase behavior
- Product and category performance
- Returns analysis
- Geographic performance
- Customer lifetime value concepts
